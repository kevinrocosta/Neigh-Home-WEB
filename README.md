## Running the Application Yourself

Here's what you need to do to get this running.

1. Register for a TMDB API key by following their instructions to be able to pull in data and images.
2. Clone the project to your machine.
3. Add the API key in the `request.js` file (or relevant config file).
4. On a command line inside of the application's folder, run `npm install` to get all the dependencies.
5. Then, run `npm start` to run the app locally.
